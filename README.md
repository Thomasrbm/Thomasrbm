<h2 align="center">🛠️ Featured Projects</h2>

<p align="center"><i>A few things I've built that I'm proud of. Each one taught me something I couldn't have learned from a tutorial.</i></p>

### ☸️ [Inception-of-Things](https://github.com/Thomasrbm/IoT_42) — *Kubernetes & GitOps*
Multi-node K3s cluster provisioned on Vagrant VMs, three apps routed by a Traefik Ingress, then K3d + Argo CD: a `git push` is the only deploy command. Bonus: GitLab self-hosted inside the cluster.
**Stack:** Kubernetes · K3s · K3d · Argo CD · Vagrant · GitLab

### ☁️ [Cloud-1](https://github.com/Thomasrbm/Cloud-1) — *Automated cloud deployment*
Takes a bare AWS EC2 instance to a TLS-terminated WordPress stack in one command: nine idempotent Ansible roles, one Docker Compose file per component, every secret in Ansible Vault.
**Stack:** Ansible · Docker Compose · AWS EC2 · nginx · UFW

### 🌐 [BADASS](https://github.com/Thomasrbm/BADASS_42) — *BGP EVPN / VXLAN fabric*
Data-center fabric in GNS3: OSPF underlay, MP-BGP EVPN control plane with a route reflector, VXLAN VTEPs learning MAC addresses without flooding.
**Stack:** FRRouting · BGP · OSPF · VXLAN · GNS3 · Docker

### 🐧 [LFS](https://github.com/Thomasrbm/ft_Linux_42) — *Linux From Scratch*
Built a working Linux distribution from source — toolchain, kernel, init system, the whole stack — to understand what actually lives under `/`.
**Stack:** GNU toolchain · Bash · Linux kernel · systemd · GRUB

### 🧠 [KFS](https://github.com/Thomasrbm/Kernel_From_Scratch_KFS_42) — *Kernel From Scratch*
Bare-metal x86 32-bit kernel written in C and NASM. VGA text mode driver, GDT with flat segmentation, PS/2 keyboard input, scrollback buffer, and a custom shell (`kash`).
**Stack:** C · NASM · GRUB · QEMU

### 🪟 [Administrative Directory](https://github.com/Thomasrbm/Administrative_Directory) — *Active Directory, GPO & SIEM*
A Windows Server forest automated in PowerShell: OUs, groups, SMB shares, GPOs (drive maps, software deployment), an NTFS permission matrix, and security auditing with log-querying scripts.
**Stack:** Windows Server · Active Directory · PowerShell · GPO
